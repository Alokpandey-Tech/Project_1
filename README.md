# Student Record Management System

## 1. Introduction

The Student Record Management System is a beginner-friendly Python
project used to manage basic student information.

The program allows the user to add, view, search, update, and delete
student records. It can also display all unique subjects entered in the
student records.

The project is created using basic Python concepts such as lists,
tuples, strings, sets, loops, conditional statements, functions, and
function calls.

## 2. Features

-   Add a new student record
-   View all student records
-   Search for a student using roll number
-   Update an existing student record
-   Delete a student record
-   Display unique subjects
-   Menu-driven program
-   Simple and easy-to-use console interface

## 3. Python Concepts Used

### Lists

The `students` list stores all student records.

### Tuples

Each student record is stored as a tuple containing roll number, name,
branch, and subjects.

### Strings

Strings are used for student names, roll numbers, branches, subjects,
and menu input.

### Sets

A set is used to store unique subjects without duplicates.

### Loops

`while` and `for` loops are used for the menu, displaying records,
searching, and processing subjects.

### Functions

Separate functions are created for different operations such as adding,
viewing, searching, updating, and deleting records.

### Conditional Statements

`if`, `elif`, and `else` are used to make decisions in the program.

## 4. How to Run

1.  Install Python 3 on your computer.
2.  Save the code as `student_management.py`.
3.  Open a terminal or command prompt in the folder containing the file.
4.  Run:

``` text
python student_management.py
```

5.  Select an option from the menu.

## 6. Data Storage

This project stores data in memory using Python lists and tuples.
Therefore, the records are lost when the program is closed.

No external database or library is required.

## 7. Limitations

-   Records are not permanently saved.
-   The program works through the console only.
-   It does not use a database.
-   It does not have a graphical user interface.
